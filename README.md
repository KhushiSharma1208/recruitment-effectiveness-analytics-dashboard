# Recruitment Effectiveness & Talent Acquisition Analytics Dashboard

## 📌 Project Overview
This project focuses on analyzing recruitment effectiveness using Excel-based People Analytics. It transforms recruitment data into meaningful insights to evaluate hiring funnel performance, recruitment sources, hiring efficiency, and recruitment costs.

## 🎯 Business Problem
Organizations need to understand which recruitment channels deliver effective hires, where candidates drop off during the recruitment process, and how efficiently hiring targets are achieved. This project uses recruitment analytics to identify improvement opportunities and support evidence-based HR decisions.

## 🎯 Project Objectives
- Analyze recruitment funnel performance from application to hiring.
- Evaluate recruitment source effectiveness.
- Track time-to-hire and time-to-fill.
- Analyze recruitment costs and candidate experience.
- Generate actionable insights to improve talent acquisition.

## 📊 Key Features
- **Recruitment Funnel Analysis:** Tracks applicants, screened candidates, interviews, offers, and hires.
- **Source Effectiveness:** Compares recruitment channels to understand their contribution to hiring.
- **Hiring Efficiency:** Analyzes time-to-hire and time-to-fill.
- **Recruitment Cost Analysis:** Examines recruitment expenditure.
- **Candidate Experience:** Reviews candidate experience scores and hiring-related outcomes.
- **Interactive Excel Dashboard:** Presents recruitment metrics and visual insights in a consolidated view.

## 📈 Key Metrics
- Total Applications
- Candidates Screened
- Candidates Interviewed
- Offers Made
- Total Hires
- Average Time-to-Hire
- Time-to-Fill
- Recruitment Cost
- Recruitment Source Performance
